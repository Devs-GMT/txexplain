      07Questions

      Short answers

      Which networks does it read?

      BOT Chain mainnet and testnet. It tries mainnet first, then testnet.

      Do I need a wallet?

      No. A wallet is only for saving a debug note or marking a fix as worked.

      Can I trust the AI summary?

      It is written from decoded facts only. A check rejects any number or hex it was not given, and a plain template takes over if the check fails.

      Why is a revert reason sometimes missing?

      Finding it can need a replay at the old block, and public RPCs often keep only recent state. When a replay is not possible, TxExplain says so and lists the usual causes.

      What does a debug note cost?

      A note is a normal transaction, so it costs a little gas in BOT. Reading notes is free.
